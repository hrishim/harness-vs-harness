Failed tests

T01 Expense claim

Failed in rounds 2, 3 (scores 62%, 92%). Lost points on: lines (60%), receipts (70%), total (0%).

What went wrong: In round 2: Added things the policy does not allow: it claimed the hotel at Rs 7,500 a night when the cap is Rs 7,000 (Rs 22,500 instead of Rs 21,000), included a laundry bill although laundry is only paid on trips of five nights or more (this trip was three), and included a cab ride at 15:10 (Rs 460), which is not an airport ride and did not start at 21:00 or later. The total came out Rs 32,280 instead of Rs 29,940. It read the photos by eye and used OCR only to pull a few words out of them. In round 3: The right ten lines and the right total, but some receipt photos were attached to the wrong lines. The model read all the photos by eye and matched each result to a file name by its position; its own notes show it was unsure which result belonged to which photo. It never tried OCR, although OCR was installed.

How the rounds differed: All rounds read the receipt photos by eye. The passing round 1 opened every photo twice (38 image reads). Round 3 opened all 19 once and then about 10 again, and it attached the wrong photos. Round 2 opened each photo once, then ran tesseract with a filter that kept only a few keywords. It was also the only round that read the policy only through the Read tool, never as text from pdftotext, and it is the round that broke the policy rules. The logs cannot show whether that caused the errors.

Failed tool calls: Two each in rounds 1 and 2, both PDF-library calls with the wrong function names, fixed on the next try.

Cost: It used 0.9× the tokens of a passing run of the same test by Claude Code, so this was not a case of extra work.

T04 Calendar conflicts

Failed in round 3 (score 93%). Lost points on: fixes (80%).

What went wrong: Its main fix for Saturday's tournament sends Arjun, whose calendar is blocked all day for Aai's surgery, the very reason the run reported the conflict. That is a new clash, which the task rules out. Kavya skipping her workshop was mentioned only as a fallback.

Cost: It used 1.3× the real tokens of a passing run of the same test by Claude Code (44K against 34K): more steps (7 instead of 5); more tool calls (8 instead of 6); longer thinking (6K instead of 4K).

T07 Tax documents (India)

Failed in rounds 1, 3 (scores 94%, 98%). Lost points on: found (93%), no extras (93%), amounts (93%), copies (93%).

What went wrong: In round 1: Read scan0042.pdf as last year's (2024-25) interest certificate and left it out, but listed the look-alike scan0043.pdf instead, so one needed document was missing and one extra was listed. In round 3: Wrote the index file by hand and put a comma inside the landlord's name note ("Prakash Joshi (landlord, PAN ZZBPJ7314K)") without quoting it. Every later column slid over, so the amount column held part of the PAN number instead of Rs 384,000.

How the rounds differed: Round 1 read the two scans by eye and mixed them up; rounds 2 and 3 ran OCR on them. Round 3 wrote the CSV by hand and never checked it.

Failed tool calls: One per round, a path or shell slip that it fixed on the next call.

Cost: It used 0.7× the tokens of a passing run of the same test by Claude Code, so this was not a case of extra work.
