Runs that were redone

44 runs were set aside and run again, because something went wrong with the run itself and not with the model's work:

  • 5 Hermes runs where a model reply never arrived and Hermes was stopped.
  • 2 Hermes runs and 1 DeepSeek run that never started.
  • 23 OpenCode runs where the first setup blocked access to files outside the task folder.
  • 4 Hermes runs that finished with trouble: three were stopped while waiting for the model, and one used the whole 45 minutes.
  • 9 runs (5 OpenCode, 2 DeepSeek, 1 Hermes, 1 Claude Code) during which the laptop running the tests went to sleep. That paused the test containers and inflated the times. The scores were the same in 7 of the 9.

The results use only the reruns. One rerun, Hermes on the bank statements test (T02) in round 2, ended the same way again: the process was terminated shortly after the model ran pkill commands on gnucash. It is kept as a real result. Every transaction was entered correctly, but the book was left locked, so it scored 90%.
