harness-vs-harness

We gave AI agent programs the same 15 everyday tasks, three times each, and measured how correct they were and what they cost to run.

What this is

A harness is the program wrapped around an AI model that lets it read files, run commands and work through a task on its own. Different harnesses can get quite different results from the same model, so we hold the model fixed and change only the harness.

The 15 tasks are things a person does on a laptop: filling in an expense claim, importing bank statements into accounting software, sorting an inbox, planning a trip, fixing a bug. Each task is given as one plain request with no follow-up questions. The answers are scored by rules and automated checks, never by another AI. Score is the percentage correct; real tokens is how much work the model did on a run (the new text it read plus everything it wrote, including its thinking).

See exactly what each task asked on the Tests page, and how everything was run (model recipe, harness versions) on the Setup page.

The results

The model is thinking-capable, and how hard it thinks depends on a setting called reasoning effort. Two harnesses ask for medium. The other two send nothing, so the server falls back to its default, xhigh, which thinks much harder. Because that changes both cost and results, compare harnesses only within the same effort level.

How to read the graphs

  • Every run is a dot, so you can see how results moved from round to round, not only the average.
  • Each harness keeps the same colour on every page.
  • Runs that failed because of a problem with the run itself (not the model's work) are left out and are listed on the Data page.
