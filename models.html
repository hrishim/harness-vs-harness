How these runs were made

Qwen3.8-Flash-Next ran as NVIDIA's NVFP4 build on vLLM on one DGX Spark, the runs of the harness comparison. Qwen3.8-27B ran rounds 1 and 3 in FP4 through OpenRouter, pinned to one provider, and round 2 as NVIDIA's NVFP4 build on vLLM on the same DGX Spark. On OpenRouter the provider was Darkbloom; where Darkbloom returned the model's tool calls as plain text, which ends a run with no answer, the run was done again, on ModelRun when Darkbloom did it again, and the rerun counts. In round 2 the DGX Spark froze during the last test (T15), so that test was run on OpenRouter instead. A setup of Qwen3.8-27B on another engine, TensorFold, froze the DGX Spark twice under these tests and is left out.
